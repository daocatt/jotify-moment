# 大佬论坛 (Dalao.net) OAuth 接入与配置指南

本文档介绍如何在 Jotify Moment 中配置并启用“大佬论坛”账号授权登录。

---

## 一、应用申请与登记

在前往大佬论坛开放平台创建应用时，请按照以下规范填写：

### 1. 回调地址 (Redirect URI)
- **协议要求**：必须使用 `https://` 协议（大佬论坛强制要求）。
- **完整路径**：
  ```text
  https://<您的站点域名>/api/auth/dalao/callback
  ```
  例如生产环境域名为 `jotify.me`，则应填写：
  ```text
  https://jotify.me/api/auth/dalao/callback
  ```
  > **注意**：填写的回调地址必须与后续服务端请求中携带的 `redirect_uri` 完全一致（包含协议、端口、路径，末尾不要有多余的 `/`）。

---

## 二、权限范围 (Scope) 说明与兼容性确认

创建应用时，权限范围包含以下三组可选范围：

| 权限组 | 对应 Scope | 建议选择 | 接口兼容性说明 |
| :--- | :--- | :--- | :--- |
| **用户 ID、用户名** | `basic` | **必需勾选 (必选)** | **系统核心凭据**。OAuth 必须依赖稳定的用户唯一标识（`sub` 或 `id`）作为账号唯一外键进行绑定关联，不可缺少。 |
| **邮箱地址** | `email` | **推荐勾选** | **完全兼容**。推荐勾选以便自动获取用户邮箱作为站内账号邮箱或匹配已有账号；若未勾选，系统会自动降级生成内部专属邮箱（如 `dalao_{id}@users.internal`），新用户仍可一键免密直接登录入驻。 |
| **头像及个人资料** | `profile` | **无需勾选 (可选)** | **完全兼容**。Jotify Moment 不需要读取论坛个人资料或头像；系统默认采用单字首字母头像，用户进入系统后可在个人设置中自主上传并裁剪专属头像和封面。 |

### 核心疑问解答：
1. **最小是不是得选择第一组权限（用户 ID、用户名）？**
   - **是的**。第一组权限是系统的绝对最小依赖。OAuth 的本质是第三方身份凭证授权，必须拥有唯一的 `sub`（用户 ID）才能在数据库的 `accounts` 表中记录对应关系。
2. **如果没有邮箱、没有头像和个人资料，我们的接口是否兼容？**
   - **100% 兼容**。
     - 若没有邮箱，系统会在入驻时自动生成 `dalao_{accountId}@users.internal` 虚拟标识，不影响任何核心功能。
     - 若没有头像和个人资料，系统使用默认首字母头像，完全解耦。
3. **用户 ID 和用户名是否可以不需要？**
   - **绝对不能不需要**。用户 ID 是底层识别唯一身份的主键，不可缺少。同时大佬论坛的 basic 权限中用户 ID 与用户名属于同一选项，勾选即可同时获得。

## 三、服务端环境变量配置

在部署服务器的 `.env` 或 `.env.prod` 文件中添加以下配置：

```env
# 大佬论坛 OAuth 配置
DALAO_OAUTH_CLIENT_ID=你的ClientID
DALAO_OAUTH_CLIENT_SECRET=你的ClientSecret

# 可选配置（默认自动使用 ${BETTER_AUTH_URL}/api/auth/dalao/callback）
# DALAO_OAUTH_REDIRECT_URI=https://jotify.me/api/auth/dalao/callback

# 可选配置：请求的权限范围
# 若在大佬论坛只勾选了第一组【用户 ID、用户名】，请显式设置为 basic：
# DALAO_OAUTH_SCOPE=basic
# 若勾选了第一组与第二组【邮箱地址】，保持默认即可（默认为 basic email）：
# DALAO_OAUTH_SCOPE=basic email
```

## 四、后台管理开关开启

本功能默认在全站保持**关闭状态**，上线部署完毕后，管理员可通过管理后台一键启用：

1. 登录超级管理员账号，进入控制台 `/admin`。
2. 切换至 **“系统设置”** 标签页。
3. 找到 **“大佬论坛账号登录”** 开关项，点击开启。
4. 开启后，前台用户登录/注册弹窗将自动出现 **“使用大佬论坛账号登录”** 按钮。

---

## 五、用户体验与账号安全设计

1. **首次授权中间确认页 (`/auth/oauth-connect`)**：
   - **直接登录 (新用户)**：免密一键创建新用户并直接进入系统，体验丝滑。
   - **绑定已有账号**：输入已有邮箱和密码完成合并关联。
2. **账号绑定与严格解绑机制**：
   - 用户在个人设置 `/settings` 的“账号与安全”中可以查看绑定状态。
   - **解绑防护规则**：若用户最初是通过“直接登录”一键入驻且尚未设置过本地独立密码，系统会**严格拦截解绑**，并提示引导用户先在下方“设置初始登录密码”，以防解绑后账号丢失或无法登录。
